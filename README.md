# AM38 Rent A Car Mauritius

Enterprise-grade tourism and fleet management platform built for Mauritius.

## Features

- Real-time bookings
- Fleet management
- Stripe payments
- Invoice generation
- CRM dashboard
- Tourism explorer
- QR trip planner
- Admin analytics
- Notification engine
- Ticket system
- Fleet maintenance
- Upload/document verification
- Socket.IO realtime updates
- PM2 production orchestration
- CI/CD pipeline
- SEO optimized

## Stack

### Frontend
- React
- Vite
- TypeScript
- TailwindCSS
- React Query
- Framer Motion
- Recharts

### Backend
- Node.js
- Express
- MySQL
- Stripe
- Socket.IO
- JWT Authentication

### Infrastructure
- PM2
- GitHub Actions
- Nginx Ready
- SSL Ready
